# sdflash — запись образов систем на карту одной командой

Инструмент восстановления X96 Max и Orange Pi после отказа карты/накопителя.

## Образы

| Устройство | Образ | Куда пишется |
|---|---|---|
| X96 Max | `images/x96-sd.tar.xz` | SD-карта (корень системы) |
| Orange Pi | `images/opi-emmc.tar.xz` | SD-карта (замена eMMC/карты) |

Образы кладутся в `tools/sdflash/images/` (или лежат на `D:\`).

## Использование (Windows, от администратора)

```bat
:: 1. посмотреть диски ноутбука
python flash.py --list

:: 2. записать образ X96 Max (спросит подтверждение — введи номер диска)
python flash.py x96max

:: 3. записать образ Orange Pi
python flash.py orangepi
```

Опции: `--image <файл>` (свой образ), `--disk N` (конкретный PhysicalDrive),
`--yes` (без подтверждения, для автоматизации).

## Безопасность

- системный диск (с Windows) исключается автоматически;
- перед записью нужно ввести номер диска;
- запись с выравниванием по секторам 512, стриминговая распаковка
  `.tar.xz` на лету (образ не распаковывается целиком на диск ноутбука).

## Обновление образа

Образ снимается с рабочего устройства:

```bat
:: X96 (диск корня смотреть через lsblk на устройстве)
plink -ssh ... "dd if=/dev/mmcblkX bs=4M conv=noerror,sync status=progress" > D:\x96-sd.img
tar -cJf D:\x96-sd.tar.xz -C D:\ x96-sd.img
```
